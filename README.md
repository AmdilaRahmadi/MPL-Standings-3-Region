# MPL-Standings & Playoff Simulation — Excel Portfolio

An Excel-based portfolio project inspired by Mobile Legends Professional League (MPL).

## Project Overview

This workbook demonstrates intermediate Microsoft Excel skills through:

- Automatic match statistics
- Match Win / Match Lose calculation
- Game Win / Game Lose calculation
- Game Difference calculation
- Automatic standings ranking
- Tiebreaker system:
  1. Matches Win
  2. Netgame Win
  3. H2H
  4. Alphabetical order
- Tiebreak match simulation
- Playoff simulation

## Features

Match scores are entered manually, while standings and ranking are updated automatically.

Tiebreak matches are separated from regular matches so they do not affect Match Win / Match Lose statistics.

## Purpose

This project was created as part of my personal portfolio to demonstrate my ability to use Microsoft Excel at an intermediate level.

The workbook is intended for learning and portfolio purposes and is not an official MPL system or real-time data source.
